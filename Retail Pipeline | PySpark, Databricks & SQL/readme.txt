Retail Data Engineering Pipeline, OVERVIEW:

An end-to-end retail data pipeline built using PySpark, Databricks, SQL, and Delta Lake. The project follows the Medallion Architecture to transform raw retail data into analytics-ready datasets.


TECHNOLOGIES:

Python & PySpark
Databricks & Delta Lake
SQL & Unity Catalog


ARCHITECTURE:

Bronze: Ingest raw CSV files and store them as Delta tables.
Silver: Transform data types and prepare datasets for analysis.
Gold: Create analytical tables for business insights:
daily_sales — Daily revenue, order counts, and average order value.
sales_by_category — Sales performance by category.
top_products — Product sales performance.


DATASETS:

Customers, orders, order items, products, categories, and departments.


KEY SKILLS:

Data ingestion, PySpark transformations, SQL joins and aggregations, Delta tables, and Medallion Architecture.
